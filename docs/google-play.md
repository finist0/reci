# Описание для Google Play

Готовые тексты для карточки приложения в Google Play Console. Ограничения Google указаны
в скобках, длина каждого текста проверена.

## Название (до 30 символов)

```
НЕРодная речь: сербский язык
```

28 символов.

## Краткое описание (до 80 символов)

```
Сербский язык по карточке на экране блокировки — для тех, кто говорит по-русски.
```

80 символов. Запасной вариант, 75 символов:

```
Сербские слова на экране блокировки: учите, каждый раз беря в руки телефон.
```

## Полное описание (до 4000 символов)

```
Вы берёте телефон в руки десятки раз в день. НЕРодная речь превращает каждый такой момент в маленький урок сербского: на экране блокировки вас ждёт одно слово — с ударением, родом, примерами и переводом на русский. Десять секунд, и слово остаётся с вами.

ПОЧЕМУ ЭТО РАБОТАЕТ

• Не нужно выкраивать время. Карточка уже на экране блокировки, учёба встраивается в ваш обычный день.
• Сначала самое нужное. Слова идут в том порядке, в каком они чаще всего звучат в живой речи.
• Вспоминать, а не перечитывать. После знакомства слово нужно вспомнить по переводу. Выученное возвращается на проверку через неделю, три недели, два месяца, полгода и год.
• Забыли — повторим сразу. Слово с ответом «Не знаю» вернётся через пять карточек, пока оно ещё свежее.

СДЕЛАНО ДЛЯ ТЕХ, КТО ГОВОРИТ ПО-РУССКИ

• Переводы и объяснения на русском.
• Предупреждения там, где сербский подводит: «проблем» мужского рода, хотя «проблема» женского.
• Ложные друзья: «празан» значит «пустой», а не «праздный».
• Разборы похожих слов: «уговор или договор?», «привремено или тренутно?».

ЧТО ВНУТРИ

• Больше 10 000 карточек: 7 300 слов, 2 000 выражений и идиом, 345 разборов похожих слов, 600 заметок о языке.
• 18 000 примеров с переводом, синонимы, антонимы, однокоренные слова.
• Ударения у слов и формы: множественное число, спряжение, вид глагола.
• Справочник по грамматике: 26 тем с таблицами склонений и спряжений.
• Уровни от A1 до C1 и 30 тем: еда, транспорт, работа, семья и другие.

УДОБНО

• Кириллица или латиница, подпись другим алфавитом.
• Произношение голосом телефона.
• Долгое нажатие на «Знаю» сразу отмечает знакомое слово выученным.
• Ошиблись — кнопка «назад» вернёт карточку, и ответ можно поменять.
• Режимы «только перевод» и «только слово».
• Поиск по сербскому слову и по переводу, избранное.
• Восемь цветовых тем, светлые и тёмные.
• Прогресс можно сохранить в файл и перенести на другой телефон, iPhone или компьютер.
• Во время звонка карточка не появляется. Пока экран выключен, приложение ничего не делает и не тратит батарею.

ЧЕСТНО

• Без рекламы и смс.
• Открытый исходный код: github.com/finist0/reci

Название отсылает к учебнику «Родная речь». На иконке — избушка на курьих ножках, которая говорит «Ђ».
```

## Что ещё понадобится в Play Console

- **Категория:** «Образование».
- **Скриншоты:** минимум два, лучше 4–8. Подойдут `screenshots/*.png` из репозитория.
- **Графический баннер** 1024×500: его пока нет, нужно нарисовать.
- **Значок** 512×512: `web/icon-512.png` подходит.
- **Политика конфиденциальности:** ссылка обязательна. В ней описать, какие данные
  приложение отправляет, зачем и как от этого отказаться.
- **Раздел «Безопасность данных»:** ответы должны совпадать с политикой
  конфиденциальности и с тем, что приложение отправляет на самом деле.
- **Разрешения, которые проверяет Google:** тексты ниже, в разделе «Объяснения для
  проверки».

## Объяснения для проверки

Тексты на английском: их читают проверяющие Google. Описание службы в манифесте тоже
английское.

### Служба переднего плана `specialUse`

Где: Play Console → App content → Foreground service permissions. Для каждой службы
Google просит описание, последствия её остановки, сценарий использования и ссылку на видео.

**Use case:** «Other», вписать вручную:

```
Vocabulary card on the lock screen when the screen turns on
```

**Description:**

```
The app shows a vocabulary card on the lock screen each time the user turns the screen on. The user turns this on in the app settings ("Card when the screen turns on"). A foreground service keeps a receiver for the SCREEN_OFF broadcast, which Android delivers only to receivers registered at run time by a running app. When the screen goes off, the service starts the card activity, so the card is already in place when the user turns the screen back on. The ongoing notification of the service can also show words the user marked for review. Turning the setting off stops the service.
```

**User impact if the task is deferred or interrupted:**

```
If the service is stopped, the card no longer appears when the user turns the screen on, and the feature the user turned on silently stops working. The work cannot be deferred: the card has to be started at the moment the screen goes off, and no scheduled or deferrable API (WorkManager, JobScheduler, alarms) runs at that moment.
```

**Видео:** запись экрана телефона, по шагам:

1. Открыть приложение → Настройки → «Карточка при включении экрана».
2. Выдать «Поверх других окон».
3. Выключить экран и включить снова: на экране блокировки карточка со словом.
4. Ответить на карточку, нажать «Готово»: карточка закрывается.
5. Опустить шторку: видно уведомление службы.
6. Выключить настройку: после выключения и включения экрана карточки больше нет.

Видео выложить на YouTube с доступом по ссылке.

### «Поверх других окон» (`SYSTEM_ALERT_WINDOW`)

Отдельной формы для этого разрешения в документации Google нет. Если проверка спросит:

```
The app needs "Display over other apps" for one feature only: to show its vocabulary card on the lock screen when the screen turns on. Android allows an app to start an activity from a background service only when it holds this permission. The permission is never requested at install time: the user grants it in the system settings after turning the lock screen card on, and the app explains beforehand why it is needed. Without it, everything else in the app keeps working.
```

### Исключение из оптимизации батареи

Приложение не запрашивает `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`: Google Play разрешает его
только приложениям, у которых без него не работает основная функция. Строка «Без
ограничений батареи» открывает страницу приложения в настройках Android, а подсказка под
ней ведёт дальше. Объяснять здесь ничего не нужно.
