# Описание для Google Play

Готовые тексты для карточки приложения в Google Play Console на трёх языках. Ограничения
Google указаны в скобках, длина каждого текста проверена скриптом (таблица в конце раздела).

Каждый язык обращается к своему читателю:

- **русский** (ru-RU): сербский для тех, кто говорит по-русски, остальные пары в конце;
- **сербский** (sr): русский для тех, кто говорит по-сербски;
- **английский** (en-US): сербский и русский с переводом на английский.

Сербский и английский добавляются в Play Console → Store presence → Main store listing →
Manage translations → Add your own translations. Кто читает на языке, для которого перевода
нет, видит язык по умолчанию. Поэтому английский разумно сделать языком по умолчанию, а
русский оставить переводом.

## Русский (ru-RU)

### Название (до 30 символов)

```
НЕРодная речь
```

### Краткое описание (до 80 символов)

```
Сербские слова на экране блокировки: с ударением, примерами и переводом
```

### Полное описание (до 4000 символов)

```
Вы берёте телефон в руки десятки раз в день. НЕРодная речь превращает каждый раз в короткий урок сербского: на экране блокировки вас ждёт слово с ударением, примерами и переводом на русский. Десять секунд, и слово остаётся с вами.

КАК ЭТО РАБОТАЕТ

• Учить можно, не выделяя время: карточка уже на экране блокировки.
• Сначала самые частые слова живой речи.
• Новое слово нужно вспомнить по переводу, а не просто прочитать.
• Выученное возвращается на проверку через неделю, три недели, два месяца, полгода и год.
• Слово с ответом «Не знаю» вернётся через пять карточек, пока оно ещё свежее.

СДЕЛАНО ДЛЯ ТЕХ, КТО ГОВОРИТ ПО-РУССКИ

• Переводы и объяснения на русском.
• Предупреждения там, где сербский подводит: «проблем» мужского рода, хотя «проблема» женского.
• Ложные друзья: «празан» значит «пустой», а не «праздный».
• Разборы похожих слов: «уговор или договор?».

ЧТО ВНУТРИ

• 16 000 карточек: 12 500 слов, 2 500 выражений и идиом, 380 разборов похожих слов, 670 заметок о языке.
• Почти 30 000 примеров с переводом.
• Ударения, род, формы, синонимы, антонимы и связанные слова.
• Справочник по грамматике: 26 тем с таблицами.
• Уровни от A1 до C1 и 30 тем.

ЕЩЁ ТРИ ПАРЫ ЯЗЫКОВ

• Русский для тех, кто говорит по-сербски: 4 200 слов с ударениями и переводом на сербский.
• Сербский и русский с переводом на английский.
• Выученное слово остаётся выученным и с другим переводом.
• Интерфейс на русском, сербском или английском.

УДОБНО

• Кириллица или латиница.
• Произношение голосом телефона.
• Долгое нажатие на «Знаю»: слово сразу выучено.
• Кнопка «назад» возвращает карточку, ответ можно поменять.
• Поиск по сербскому слову и по переводу, избранное.
• Восемь цветовых тем, светлые и тёмные.

```
Телефон узмете у руке десетине пута дневно. НЕРодная речь сваки тај тренутак претвара у кратак час руског: на закључаном екрану чека вас реч са акцентом, примерима и преводом на српски. Десет секунди, и реч остаје с вама.

• Поређења сличних речи и белешке: „идти или ехать?“

ЈОШ ТРИ ЈЕЗИЧКА ПАРА

  заново — см. «Снимки экранов» в [development.md](development.md).
  `StoreScreenshots.kt` снимает русский интерфейс и сербский с русским переводом. Пока
  своих снимков у сербской и английской страниц нет, Google Play показывает на них снимки
  языка по умолчанию.
- **Графический баннер** 1024×500: `art/feature-graphic.png`. Он рисуется из
  `art/feature-graphic.html` командой `node art/feature-graphic.mjs`, нужен Google Chrome.

## Объяснения для проверки

Тексты на английском: их читают проверяющие Google. Описание службы в манифесте тоже
английское.

### Служба переднего плана `specialUse`

Где: Play Console → App content → Foreground service permissions. Для каждой службы
Google просит описание, последствия её остановки, сценарий использования и ссылку на видео.

**Use case:** «Other», вписать вручную:

```
Vocabulary card on the lock screen when the screen turns on
```

**Description:**

```
The app shows a vocabulary card on the lock screen each time the user turns the screen on. The user turns this on in the app settings ("Card when the screen turns on"). A foreground service keeps a receiver for the SCREEN_OFF broadcast, which Android delivers only to receivers registered at run time by a running app. When the screen goes off, the service starts the card activity, so the card is already in place when the user turns the screen back on. The ongoing notification of the service can also show words the user marked for review. Turning the setting off stops the service.
```

**User impact if the task is deferred or interrupted:**

```
If the service is stopped, the card no longer appears when the user turns the screen on, and the feature the user turned on silently stops working. The work cannot be deferred: the card has to be started at the moment the screen goes off, and no scheduled or deferrable API (WorkManager, JobScheduler, alarms) runs at that moment.
```

**Видео:** запись экрана телефона, по шагам:

1. Открыть приложение → Настройки → «Карточка при включении экрана».
2. Выдать «Поверх других окон».
3. Выключить экран и включить снова: на экране блокировки карточка со словом.
4. Ответить на карточку, нажать «Готово»: карточка закрывается.
5. Опустить шторку: видно уведомление службы.
6. Выключить настройку: после выключения и включения экрана карточки больше нет.

Видео выложить на YouTube с доступом по ссылке.

### «Поверх других окон» (`SYSTEM_ALERT_WINDOW`)

Отдельной формы для этого разрешения в документации Google нет. Если проверка спросит:

```
The app needs "Display over other apps" for one feature only: to show its vocabulary card on the lock screen when the screen turns on. Android allows an app to start an activity from a background service only when it holds this permission. The permission is never requested at install time: the user grants it in the system settings after turning the lock screen card on, and the app explains beforehand why it is needed. Without it, everything else in the app keeps working.
```

### «Звонки» (`READ_PHONE_STATE`)

Разрешение необязательное, его выдают в настройках приложения. Отдельной формы для него
нет. Если проверка спросит:

```
The phone permission is optional. The app uses it only to ask Android whether a call is going on (TelecomManager.isInCall), so that the lock screen card does not appear over a call. Without it the app falls back to the audio mode, and some messengers leave the ringing mode set after their calls end, which stops the cards. A talk in a messenger that does not report to Telecom is still told by the communication mode. The app does not make calls and does not read phone numbers.
```

### Исключение из оптимизации батареи

Приложение не запрашивает `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`: Google Play разрешает его
только приложениям, у которых без него не работает основная функция. Строка «Без
ограничений батареи» открывает страницу приложения в настройках Android, а подсказка под
ней ведёт дальше. Объяснять здесь ничего не нужно.
